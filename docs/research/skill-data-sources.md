# FFXIV 기술 데이터 수집 방식 조사

## 1. 조사 목적

FFXIV Damage Simulator의 직업별 기술 데이터 구축에 필요한 정보 출처 및 관리 방식을 결정한다.

지원 예정 레벨은 70, 80, 90, 100이며, 패치별 기술 위력과 효과의 차이를 반영한다.

## 2. 주요 데이터 출처

### XIVAPI v2

- URL: https://v2.xivapi.com/
- 문서: https://v2.xivapi.com/docs/welcome/
- 게임 클라이언트 데이터 기반 API
- Action, ActionTransient 등 기술 관련 데이터 조회 가능
- 게임 버전 및 스키마 고정 기능 지원
- 7.0 이후 패치 기록 제공
- 한국어 데이터 미지원

**활용 방향:** 기술 ID, 이름, 데이터 필드, 아이콘 참조 등 구조화된 정보 확보

### 한국 공식 직업 가이드

- URL: https://guide.ff14.co.kr/
- 한국어 기술명 및 기술 설명 확인
- 기술 위력, 재사용 시간, 콤보 조건, 버프 및 직업 메커니즘 검증
- 최신 패치 기준으로 갱신되므로 과거 패치 자료와 구분 필요

**활용 방향:** 한국어 표기 및 실제 기술 효과 교차 검증

### FFXIV Datamining

- URL: https://github.com/xivapi/ffxiv-datamining
- CSV 기반 게임 데이터 및 변경 이력 제공
- 패치별 데이터 비교에 활용 가능
- 과거 확장팩 데이터는 별도 가용성 확인 필요

**활용 방향:** 데이터 구조 조사 및 패치별 차이 확인

### 한국어 데이터 저장소

- URL: https://github.com/Ra-Workspace/ffxiv-datamining-ko
- 한국 클라이언트 관련 데이터
- 패치 태그와 한국어 CSV 자료 확인 가능
- 글로벌 버전과 국내 버전의 차이를 고려해야 함

## 3. 수집 대상

| 항목 | 확보 방식 |
|---|---|
| 기술 ID / 직업 / 습득 레벨 | XIVAPI 및 게임 데이터 |
| 기술 이름 | 한국어 자료와 ID 대조 |
| GCD / oGCD | 기술 유형 및 재사용 시간 검증 |
| 기술 위력 | 기술 설명 및 패치별 수치 검증 |
| 콤보 조건 | 기술 설명 및 직업 규칙 검증 |
| 쿨타임 / 충전 횟수 | 데이터 필드 및 공식 가이드 |
| 버프 / 시너지 | 공식 설명과 적용 규칙 대조 |
| 직업 자원 획득·소비 | 기술별 발동 조건을 확인하여 구조화 |
| 기술 아이콘 | 허용된 사용 범위 내에서 참조 |

## 4. 패치 및 레벨 관리

- 패치 버전은 문자열로 저장한다.
- 직업, 레벨, 패치의 조합을 데이터 식별 기준으로 사용한다.
- 글로벌·한국 패치의 데이터 출처와 기준을 명시한다.
- 레벨 조율된 최신 기술과 과거 패치 기술을 혼동하지 않는다.
- 7.0 이전 데이터 확보 방법은 추가 조사한다.
- 기술 데이터가 최신 버전으로 자동 변경되지 않도록 버전을 고정한다.

## 5. 직업 자원 및 특수 효과

기술 데이터만으로 계산 규칙이 완성되지 않는 경우가 있다.

별도로 검증할 항목:

- 자원 획득 및 소비 조건
- 콤보 성공 여부
- 직업 게이지 최대치
- 특성에 따른 기술 변경
- 기술 사용 가능 상태
- 버프 중복 및 갱신
- 방향 지정 및 지속 피해
- 특정 레벨에서의 기술 대체

이러한 조건은 향후 직업별 규칙 모델과 계산 엔진에서 처리한다.

## 6. 저작권 및 이용 조건

- 게임 데이터와 기술 아이콘의 출처를 기록한다.
- 공개 서비스 및 공개 저장소에서의 이용 조건을 별도로 검토한다.
- 원본 이미지와 설명문의 무단 대량 재배포를 피한다.
- 상업·영리 목적 이용 제한을 확인한다.
- 필요한 저작권 및 상표 고지를 적용한다.

## 7. 결론

다음과 같은 데이터 구축 방식을 우선 검토한다.

1. XIVAPI v2 및 패치별 자료에서 기술 정보 확보
2. 한국어 명칭과 기술 효과 교차 검증
3. 직업별 특수 규칙 수동 보완
4. 패치별 JSON 데이터로 정규화
5. Pydantic 모델을 통해 검증 후 FastAPI 제공

## 8. 후속 작업

- XIVAPI v2 실제 요청과 응답 구조 검증
- 용기사 실제 기술 데이터 수집
- 직업별 특수 효과 모델 확장
- 레벨 및 패치별 데이터 관리 방식 구현
- 이용 조건 확인 후 기술 아이콘 연동
