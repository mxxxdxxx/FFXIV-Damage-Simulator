# FFXIV-Damage-Simulator

**파이널판타지14 스킬 로테이션 및 기대 피해량 계산 시뮬레이터**

FFXIV Damage Simulator는 파이널판타지14의 직업별 기술과 시너지 효과를 바탕으로 사용자가 직접 스킬 로테이션을 구성하고, 예상 피해량을 계산하고 비교할 수 있는 웹 서비스입니다.

GCD(Global Cooldown)와 oGCD(Off Global Cooldown) 기술을 자유롭게 배치하고, 선택한 파티 시너지에 따른 기대 피해량의 변화를 확인할 수 있습니다.

> **개발 상태:** 기획 및 초기 개발 단계

## 주요 기능

### 1. 확장팩별 스킬 설정
- 홍련의 해방자 (Lv.70)
- 칠흑의 반역자 (Lv.80)
- 효월의 종언 (Lv.90)
- 황금의 유산 (Lv.100)
- 선택한 확장팩에 대응하는 기술 및 전투 규칙 적용

### 2. 자유로운 스킬 로테이션 구성
- 직업별 GCD / oGCD 기술 목록 제공
- 드래그 앤 드롭 방식의 스킬 배치
- GCD 사이에 oGCD 기술 삽입
- 기술 순서 변경, 추가 및 삭제
- 전투 시간 입력 없이 자유롭게 로테이션 구성

### 3. 파티 시너지 설정
- 시너지를 제공하는 파티 직업 선택
- 선택한 직업의 시너지 기술 적용
- 시너지 발동 위치 설정
- 시너지 적용 전후 개인 기대 피해량 계산

### 4. 스킬 타임라인
- 배치한 스킬을 시간순으로 시각화
- GCD / oGCD 사용 시점 표시
- 버프 적용 구간 및 지속시간 표시
- 스킬 사용 가능 여부 검증

### 5. 사이클 비교 모드
- 선택적으로 A/B 비교 모드 활성화
- 두 가지 스킬 로테이션 구성 및 수정
- 총 기대 피해량 및 DPS 비교
- 시너지 효과와 스킬별 피해량 비교

## 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | Next.js, TypeScript, Tailwind CSS |
| Backend | FastAPI, Python |
| Database | PostgreSQL (도입 예정) |
| Drag & Drop | dnd-kit |
| State Management | Zustand |
| Data Collection | XIVAPI, FFXIV Game Data |
| Version Control | Git, GitHub |

※ 기술 스택은 개발 과정에서 변경될 수 있습니다.

## 시스템 구성

```text
Next.js Frontend
    │
    ├── 확장팩 및 직업 선택
    ├── 스킬 로테이션 편집
    ├── 시너지 설정
    ├── 타임라인 시각화
    └── 사이클 비교
    │
    ▼
FastAPI Backend
    │
    ├── 기술 데이터 조회
    ├── GCD / oGCD 사용 시간 계산
    ├── 콤보 및 버프 처리
    ├── 기대 피해량 계산
    └── 시뮬레이션 결과 반환
    │
    ▼
Game Data / Database
```
