# FFXIV Damage Simulator

**파이널판타지14 스킬 로테이션 및 기대 피해량 계산 시뮬레이터**

FFXIV Damage Simulator는 파이널판타지14의 직업별 기술과 시너지 효과를 바탕으로 사용자가 직접 스킬 로테이션을 구성하고, 기대 피해량을 계산할 수 있는 웹 기반 시뮬레이터입니다.

GCD(Global Cooldown)와 oGCD(Off Global Cooldown) 기술을 자유롭게 배치하고, 캐릭터의 GCD 설정 및 선택한 파티 시너지에 따른 피해량 변화를 확인할 수 있습니다.

또한 선택형 비교 모드를 통해 서로 다른 스킬 로테이션의 기대 피해량과 DPS를 비교할 수 있습니다.

> **프로젝트 상태:** 기획 및 초기 개발 단계  
> 본 README의 기능 설명은 개발 목표이며, 실제 구현 여부는 개발 로드맵을 참고해 주세요.

## 주요 기능

### 1. 확장팩별 스킬 설정

다음 확장팩 및 레벨을 지원하는 것을 목표로 합니다.

| 확장팩 | 레벨 |
|---|---|
| 홍련의 해방자 | Lv.70 |
| 칠흑의 반역자 | Lv.80 |
| 효월의 종언 | Lv.90 |
| 황금의 유산 | Lv.100 |

- 확장팩별 사용 가능한 직업 및 기술 제공
- 레벨 및 패치에 따른 기술 위력과 효과 반영
- 확장팩별 직업 특성과 전투 규칙 적용

※ 과거 확장팩 당시의 전투 환경 재현과 현재 패치 기준 레벨 조율은 서로 다른 계산 방식이므로, 구체적인 지원 범위는 개발 과정에서 확정할 예정입니다.

### 2. 자유로운 스킬 로테이션 구성

사용자가 직접 기술을 배치하여 원하는 로테이션을 구성할 수 있습니다.

- 직업별 GCD / oGCD 기술 목록 제공
- 드래그 앤 드롭 방식의 스킬 배치
- GCD와 oGCD를 분리한 편집 영역 제공
- GCD 사이에 oGCD 기술 삽입
- 기술 순서 변경, 추가 및 삭제
- 전투 시간이나 프리셋 지정 없이 자유롭게 로테이션 구성
- 배치된 기술의 콤보 및 재사용 대기시간 검증

사용자는 기술의 순서와 위치를 지정하며, 시스템이 설정된 GCD와 기술별 사용 시간을 바탕으로 실제 경과 시간을 자동 계산합니다.

### 3. 사용자 GCD 및 능력치 설정

장비와 마테리아 세팅에 따라 달라지는 캐릭터의 GCD를 계산에 반영합니다.

**간편 설정**
- 사용자 기본 GCD 직접 입력
- 예시: 2.50초 / 2.45초 / 2.40초
- 입력한 GCD를 기준으로 기술 사용 시간 자동 계산

**상세 설정 (확장 기능)**
- 기술 시전 속도(Skill Speed) 능력치 입력
- 마법 시전 속도(Spell Speed) 능력치 입력
- 확장팩 및 레벨별 계산식 적용
- 기술별 기본 재사용 시간과 직업 특성 반영
- 장비 및 마테리아 능력치에 따른 GCD 계산

**GCD 설정 반영 항목**
- GCD 기술 사이의 사용 간격
- oGCD 끼워넣기(Weaving) 가능 여부
- 애니메이션 지연 및 GCD 밀림(Clipping)
- 버프 지속시간 내 사용 가능한 기술
- 로테이션 전체 소요 시간
- 기대 피해량 및 DPS

일부 기술은 별도의 재사용 시간이나 특수 효과를 가지므로 모든 GCD 기술에 동일한 재사용 시간을 일괄 적용하지 않습니다.

※ GCD 직접 입력 모드는 주로 로테이션의 시간 계산에 사용하며, 상세 능력치 모드에서는 시전 속도가 지속 피해 및 자동 공격 등에 미치는 영향도 계산하도록 확장할 예정입니다.

### 4. 파티 시너지 설정

사용자가 필요한 파티 시너지를 직접 추가할 수 있습니다.

- 내 직업을 기준으로 개인 기대 피해량 계산
- 시너지를 제공하는 다른 직업 선택
- 선택한 직업의 파티 시너지 기술 제공
- 외부 시너지 발동 위치 설정
- 버프 지속시간 및 적용 조건 반영
- 시너지 적용 전후 기대 피해량 비교

시너지를 선택하지 않은 경우 개인 기술과 자체 버프만으로 계산합니다.

파티 시너지를 추가하더라도 다른 파티원의 공격 로테이션이나 피해량은 계산하지 않으며, **외부 시너지가 내 직업의 기대 피해량에 미치는 영향만 계산**합니다.

### 5. 기대 피해량 계산

사용자가 구성한 로테이션을 바탕으로 기술별 및 전체 기대 피해량을 계산합니다.

주요 계산 요소는 다음과 같습니다.

- 기술 기본 위력 및 콤보 위력
- 캐릭터 능력치 및 직업 특성
- 사용자 지정 GCD 및 기술별 재사용 시간
- GCD / oGCD 사용 간격
- 재사용 대기시간 및 기술 발동 조건
- 개인 버프 및 외부 파티 시너지
- 극대화(Critical Hit) 및 직격(Direct Hit) 확률
- 극대화·직격 발생에 따른 피해량 변화

**계산 결과**

| 항목 | 설명 |
|---|---|
| 기대 피해량 | 극대화·직격 발생 확률 등을 반영한 평균 기대값 |
| 최소 피해량 | 계산 조건에서 가능한 이론적 최소 피해량 |
| 최대 피해량 | 계산 조건에서 가능한 이론적 최대 피해량 |
| 기대 DPS | 자동 계산된 전투 시간 기준 초당 기대 피해량 |
| 시너지 기여량 | 외부 시너지로 증가한 기대 피해량 |
| 총 소요 시간 | 배치한 로테이션의 자동 계산된 실행 시간 |

극대화와 직격은 확률적으로 발생하므로 실제 전투 피해량은 기대값과 다를 수 있습니다.

향후 확률 시뮬레이션을 통해 피해량 분포와 5~95% 예상 범위를 제공하는 기능도 검토할 예정입니다.

### 6. 스킬 타임라인 시각화

사용자가 배치한 기술을 실제 사용 시각에 따라 타임라인으로 표시합니다.

- GCD / oGCD를 구분한 타임라인
- 기술 아이콘을 활용한 사용 순서 시각화
- 사용자 GCD 설정에 따른 기술 배치 간격 자동 조정
- GCD 사이의 oGCD 끼워넣기 표시
- 개인 버프 및 외부 시너지 적용 구간 표시
- 기술별 기대 피해량 및 버프 적용 여부 확인
- 쿨타임, 콤보 및 기술 사용 조건 위반 시 경고 표시
- GCD 밀림(Clipping) 발생 시 경고 표시

사용자가 GCD 또는 기술 배치를 수정하면 계산 결과와 타임라인에 변경 사항이 반영되도록 구현할 예정입니다.

### 7. 사이클 비교 모드

기본적으로 하나의 로테이션을 편집하며, 사용자가 원하는 경우 비교 모드를 활성화할 수 있습니다.

- 사이클 A / B 각각 구성
- 기존 사이클을 복사하여 다른 사이클 제작
- 두 사이클의 기술 배치 개별 수정
- 총 기대 피해량 및 기대 DPS 비교
- 시너지 기여량 비교
- 스킬별 피해량 차이 분석
- GCD 설정을 반영한 소요 시간 비교

기본적으로 두 사이클에 동일한 캐릭터 능력치를 적용하며, 추후 서로 다른 GCD 세팅을 비교하는 기능도 지원할 예정입니다.

서로 길이가 다른 사이클도 비교할 수 있도록 총 피해량과 DPS를 함께 제공합니다.
